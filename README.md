# 🧋 Starbucks Beverage Insights Dashboard

## 📊 Project Overview

The **Starbucks Beverage Insights Dashboard** is an interactive data visualization project designed to explore and analyze Starbucks beverage data.

This dashboard provides meaningful insights into beverage categories, nutritional information, caffeine content, sugar levels, calorie distribution, and Starbucks' global presence.

The project transforms raw beverage data into meaningful visual insights through an attractive and user-friendly dashboard.

## 🎯 Project Objectives

- Analyze different Starbucks beverage categories.
- Understand average sugar and calorie content.
- Compare caffeine levels across beverage categories.
- Identify beverages with the highest caffeine content.
- Explore beverage category distribution.
- Analyze Starbucks' global presence.
- Present key business insights through interactive visualizations.

## 📌 Key Performance Indicators (KPIs)

The dashboard includes four important KPI cards:

| KPI | Value |
|---|---:|
| Total Beverages | 33 |
| Average Sugar | 32.90 |
| Average Calories | 193.78 |
| Average Caffeine | 81.69 |

## 📈 Dashboard Visualizations

The dashboard includes:

1. **Average Calories by Beverage Category** – Compares calorie levels across beverage categories.
2. **Starbucks Global Presence** – Displays Starbucks' geographical presence across the world.
3. **Beverage Category Distribution** – Shows the distribution of beverages across different categories.
4. **Average Caffeine by Category** – Compares average caffeine content across beverage categories.
5. **Top 5 Highest Caffeine Beverages** – Highlights beverages with the highest caffeine content.

## 🎛️ Interactive Filters

- Protein Range – Filter beverages according to protein range.
- Beverage Prep – Filter beverages by preparation type.

## 💡 Key Insights

- The dashboard tracks 33 beverages.
- Average sugar content is 32.90.
- Average calorie content is 193.78.
- Average caffeine content is 81.69.
- Coffee has the highest displayed average caffeine value among the categories.
- Beverage categories show different nutritional and caffeine patterns.
